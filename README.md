# Список покупок (Shopping List App) - Реліз 72

Веб-додаток для зручного керування списками покупок, каталогом товарів, улюбленими продуктами та швидким пошуком.

## Особливості релізу 72:
- Виправлено навігацію каталогу після додавання товару через пошук (тепер кнопка "Додати з каталогу" коректно закриває вікно та відкриває повний каталог товарів із очищеним пошуком).
- Покращена швидка навігація між списком, каталогом, улюбленими та списками.
- Повністю адаптивний інтерфейс для мобільних пристроїв та ПК.
